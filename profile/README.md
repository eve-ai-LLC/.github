## Deployments

**All deployments now ship from `main`.** Nothing deploys from any other branch.

## Git Workflow

We follow **Gitflow**. Read it before your first PR: [Gitflow Workflow →](https://www.atlassian.com/git/tutorials/comparing-workflows/gitflow-workflow)

Quick version:

| Branch | Purpose |
| --- | --- |
| `main` | Production. Deployable at all times. |
| `dev` | Integration branch for the next release. |
| `feat/*` | Branch from `dev`, merge back into `dev`. |
| `release/*` | Branch from `develop`, merge into `main` **and** `dev`. |
| `fix/*` | Branch from `main`, merge into `main` **and** `dev`. |
